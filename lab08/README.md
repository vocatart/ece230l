## Lab Questions

### In plain English describe the function and use of a multiplexer.

A multiplexer takes multiple inputs and uses other signals to decide which signal to send as the output.

### In plain English describe the function and use of a demultiplexer.

A demultiplexer does the opposite, taking one input and sending it to one of many outputs

### What other uses might these circuits have? (Think Shannon’s)

Using Shannon's Expansion, a multiplexer can implement any boolean function for simplifying logic circuits.
